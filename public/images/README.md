# Изображения AK BERMET

Финальный публичный релиз использует проверенные локальные фотографии комплекса из `public/images`. Структура по разделам:

- `brand/`        — логотип и знаки бренда
- `hero/`         — фоны hero-блоков страниц
- `rooms/`        — номера и коттеджи
- `garden/`       — Garden Rooms 2026
- `hot-springs/`  — горячие источники
- `spa/`          — SPA & Wellness
- `events/`       — конференц-залы и мероприятия
- `food/`         — питание и рестораны
- `territory/`    — территория, пляж, озеро
- `placeholders/` — только фирменные локальные fallback-изображения

## Логотип

В `brand/` лежат готовые файлы:

- `logo-ak-bermet.png` — основной горизонтальный логотип
- `logo-ak-bermet-light.png` — светлый вариант
- `logo-ak-bermet-stacked.png` — вертикальная компоновка
- `logo-mark.png` — только знак

Компонент `src/components/ui/Logo.tsx` использует локальный бренд-логотип и текстовый fallback при недоступности файла.

## Политика публичных фотографий

- В финальном релизе не использовать Unsplash/stock как runtime-источник.
- Публичные фотографии должны быть локальными проверенными материалами AK BERMET либо фирменным локальным fallback.
- Новое фото сначала добавляется в соответствующую папку `public/images/...`, затем его локальный путь подключается в data/component слое.
- Не использовать чужие, водяные или неподтверждённые изображения.

## Рекомендации по фото

- Для широких блоков использовать качественные горизонтальные снимки, ориентир — от ~1600 px по ширине.
- Предпочтительны `.webp` или оптимизированные `.jpg`.
- Имена файлов — латиницей, без пробелов.
- Не менять фактическое содержание фотографии генеративными дорисовками при публикации как реального фото объекта.
