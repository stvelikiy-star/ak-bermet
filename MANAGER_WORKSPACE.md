# Кабинет менеджера (Stage 08)

Рабочая зона `/manager` для обработки заявок Ак-Бермет. Это **архитектурная
(демо) версия**: без настоящей авторизации, без базы данных, на mock-данных.

> ⚠️ Не использовать manager pages в production без авторизации.

## Страницы

- `/manager` — обзор: статистика, последние заявки, задачи, важные правила.
- `/manager/leads` — CRM заявок: фильтры (статус/интерес/источник/поиск),
  таблица (desktop) и карточки (mobile), детальный просмотр со сменой статуса
  и комментарием менеджера (пока только UI-state).
- `/manager/availability` — занятость номеров (mock), формулировка
  «предварительно свободно», предупреждение о сверке с 1С.
- `/manager/rooms` — номерной фонд (mock), кнопки «Добавить номер» / «Импорт из
  Google Sheets» пока disabled.
- `/manager/payments` — оплаты (mock), правило про реквизиты.
- `/manager/reports` — демо-аналитика (cards + bars, без chart-библиотек).
- `/manager/settings` — read-only: контакты, параметры бронирования, статусы
  интеграций.

## Данные (mock)

`src/data/manager-mock.ts` — 12 заявок разных типов и статусов, оплаты,
реестр номеров (из `mockRooms`), задачи, бизнес-правила. Типы —
`src/types/manager.ts`. Утилиты — `src/lib/manager-utils.ts`.

## Статусы заявок

new, in_progress, waiting_admin, waiting_prepayment, prepaid, confirmed,
cancelled, lost.

## Как менеджер работает с заявками

Открыть заявку → проверить детали → связаться с клиентом (WhatsApp с готовым
текстом) → менять статус по мере обработки → оставлять комментарий. Финальная
бронь — только после проверки наличия и предоплаты 20%.

(PIN + защита маршрутов). До этого раздел нельзя открывать в production.
